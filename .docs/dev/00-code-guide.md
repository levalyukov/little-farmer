# Стиль написания кодаs

Для читабельного вида и интуитивного понятного код всегда пишется в едином стиле.

Для этого в проекте используется python библиотека [gdtoolkit](https://github.com/Scony/godot-gdscript-toolkit), 
которая отвечает за проверку на синтаксические ошибки, а также форматирование кода.

* Максимальная ширина строки - 120
* Табы - 4

```py
py helper.py
```

## Файлы

Название файлов пишется в стиле `snake_case`.

**Пример:**
```
animal_manager.gd
```

## Функции

Название функции пишется в стиле `snake_case` и обязательно пишется возвращаемый тип данных. Отступы - 4 таба.

**Пример:**
```gdscript
func update_spawn() -> void:
	current_spawn = get_spawn(animal_manager.get_animal(self)["house"])
```

## Переменные 

Название переменных пишется в `snake_case`, константы пишутся так же, но в верхнем регистре. Каждая переменная должная иметь тип данных. Для лучшего вида стоит константы определять раньше обычных переменных.

**Пример:**
```gdscript
const SPEED: int = 15
const TEXTURES: Dictionary = {
	0: preload("res://assets/player/idle.png"),
	1: preload("res://assets/player/walk.png"),
	2: preload("res://assets/player/run.png")
}

var hp: int = 100
var stamina: int = 100
```

## Перечисления

Название перечисление пишется в `PascalCase`.

```gdscript
enum Phases {PLANTED, GROWING, REQUIRES_WATERING, GROWED, DEAD}
```

## Сигналы

Настрого запрещается подключать сигналы через фильтр сигналов. Исключительно через код.

```gdscript
@onready var button: Button = $Button

func hello_world() -> void:
	button.pressed.connect(_button_hover)

func _button_hover() -> void:
	SoundManager.play_sound("ui/click")
	# ...
```

## Комментарии

Понятные комментарии - залог счастливого разработчика. В начале модуля пишется краткое применение модуля и, по возможности, описание методов. Но главное - функции должны быть самокомментируемым, но если нужно прояснить момент в функции комментарием - будет только лучше. 

```gdscript
# =============================================================================================
# (script.gd)
# =============================================================================================
# Описание скрипта
#
# ЗОНА ОТВЕТСТВЕННОСТИ:
# - 
#
# ОСНОВНОЙ ФУНКЦИОНАЛ:
# -
#
# ЗАВИСИМОСТИ:
# - 
# =============================================================================================
```
