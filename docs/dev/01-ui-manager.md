# Менеджер пользовательского интерфейса `(UIManager)`

`UIManager` - Глобальный синглтон, позволяющий создавать и удалять узлы пользовательских интерфейсов.

Для удобства существует единая константа `MENUS`, в которой хранятся все базовые пользовательские интерфейсы игры. Обращаться к ней можно следующим образом: `UIManager.MENUS.OBJECT` - вместо `OBJECT` подставляется доступное значения: 

- `PAUSE` - Меню паузы
- `OPTIONS` - Игровые настройки
- `CREDITS` - Титры и авторы игры

> [!WARNING]  
> Все заготовленные узлы загружаются единожды при запуске игры.

## Методы

Добавляет пользовательский интерфейс в контейнер `ui`. Если такой пользовательский интерфейс уже есть в контейнере - метод узел не добавит.

```gdscript
func ui_add(object:PackedScene) -> void:
```

Удаляет существующий в контейнере `ui` узел пользовательского интерфейса. Если переданный узел отсутвует в контейнере - ничего не произойдет.

```gdscript
func ui_remove(object:PackedScene) -> void:
```

## Пример кода

Данный код позволяет на нажатие кнопки создавать меню паузы.

```gdscript
extends Control

@onready var button:Button = $Button

func _ready() -> void:
    button.pressed.connect(
        func() -> void:
            UIManager.ui_add(UIManager.MENUS.PAUSE)
    )
```
